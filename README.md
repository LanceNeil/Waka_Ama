# Waka Ama Extractor
This program is created in order to analyze and create a  ranking system for the WakaNats2017 and 2018 event. 

## Installation
Clone the repository
`git clone https://github.com/LanceNeil/Waka_Ama`

Install the customtkinter
`pip install customtkinter`

Run the program
`Python GUI_V2.py`
